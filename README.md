# LAGO AI — 홈 (UI 프로토타입)

LAGO AI 앱의 화면 프로토타입이에요. 실제 AI는 연결되지 않았고, 예시 답변과 브라우저 저장소(localStorage)로 동작해요.

- `index.html` — 앱 전체: 이메일 로그인/가입, 대화(FACT · 빠른 생각 · THINK), 코드(빠른 CODE · CODE), 프로젝트, 에이전트, 임시 대화, 공유, 요금제, 사용량, 설정, 보호자 화면, 아이 계정(LAGO Goccia)
- `brand.html` — 로그인 화면용 3D 브랜드 애니메이션

모델: Fonte 1.0 (FACT) · Torrente 1.0 (빠른 생각) · Mare 1.0 (THINK) · Code Spruzzo 1.0 · Code Corrente 1.0
