# LAGO 크롬 확장 프로그램

브라우저 옆 패널에서 LAGO를 써요. (Chrome · Edge · Brave 등 크롬 계열, 버전 114 이상)

## 설치
1. `lago-chrome.zip` 의 압축을 풀어요. (GitHub Releases 또는 LAGO 사이트의 ‘앱 받기’)
2. 주소창에 `chrome://extensions` 를 열고 오른쪽 위 **개발자 모드**를 켜요.
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더를 골라요.
4. 퍼즐 아이콘에서 LAGO를 고정(핀)하면 한 번에 열려요.

## 쓰는 법
- 아이콘을 누르면 **옆 패널**이 열려요. 대화 · 코드를 바꿔 가며 물어볼 수 있어요.
- **이 페이지 요약**: 보고 있는 글을 핵심만 정리해 줘요.
- **선택한 글 설명**: 페이지에서 글을 드래그한 뒤 눌러요. 또는 오른쪽 클릭 → *LAGO에게 설명 부탁*.
- **이 페이지에 질문**: 페이지 내용을 붙인 채로 계속 물어봐요.
- 지난 대화는 시계 아이콘에서 다시 열 수 있어요. 대화는 이 브라우저에만 저장돼요.

## 로그인
- 이메일 · 비밀번호, 또는 Google로 가입했다면 LAGO 사이트 → 계정 메뉴 → **앱 받기** → ‘연결 코드 복사’ 를 붙여 넣어요.
- 로그인하지 않으면 위키백과 내용만 보여 줘요.

## 개인정보
- 페이지 내용은 **버튼을 눌렀을 때만** 읽고, LAGO 서버로만 보내요. 처음 읽을 때 한 번 허락을 물어봐요.
- 로그인 정보는 브라우저 안(chrome.storage)에만 있어요. 로그아웃하면 지워져요.
